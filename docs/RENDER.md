# Гузоштани MathLib BSU Pro дар Render (ройгон)

Ҳама чиз дар файли `render.yaml` омода аст. Render сайт ва базаи маълумотро **худаш** месозад.
Шумо танҳо якчанд клик мекунед ва 3 қиматро менависед.

---

## Қадами 1. Merge кардани PR

GitHub → репозиторий `mathlib-bsu-pro` → **Pull requests** → PR #2 → **Merge pull request** → **Confirm merge**.

> Ин ҳатмист: Render рамзро аз шохаи `main` мегирад.

## Қадами 2. Эҷоди Blueprint дар Render

1. Ба <https://dashboard.render.com> ворид шавед.
2. Тугмаи **New +** → **Blueprint**.
3. Репозиторий **Simple1414/mathlib-bsu-pro**-ро интихоб кунед → **Connect**.
   (Агар он дар рӯйхат набошад: **Configure account** → ба Render дастрасӣ ба ин репозиторий диҳед.)
4. **Blueprint Name**: `mathlib-bsu` нависед.
5. Render ду чизро нишон медиҳад: базаи `mathlib-db` ва сайти `mathlib-bsu`, ҳар ду **Free**.
6. Се майдонро пур кунед (ин маълумоти ворид шудан ба сифати админ аст):

   | Майдон | Чӣ нависед |
   |---|---|
   | `ADMIN_USERNAME` | логини админ, масалан `admin` |
   | `ADMIN_PASSWORD` | пароли қавӣ, **ҳадди ақал 10 аломат** (ҳарфҳо + рақамҳо + аломат) |
   | `ADMIN_EMAIL` | почтаи шумо |

7. **Apply**-ро пахш кунед.

## Қадами 3. Интизор шавед (5–10 дақиқа)

**Dashboard** → `mathlib-bsu` → **Logs**. Вақте ки ин сатрҳоро бинед, сайт тайёр аст:

```
ensure_admin: admin 'admin' created.
Listening at: http://0.0.0.0:10000
==> Your service is live 🎉
```

## Қадами 4. Кушодани сайт

Силка дар болои саҳифаи `mathlib-bsu` дар Render навишта шудааст, одатан:

**https://mathlib-bsu.onrender.com**

> Агар ин ном аллакай аз они каси дигар бошад, Render ба охираш ҳарфҳо илова мекунад
> (масалан `mathlib-bsu-x1y2.onrender.com`). Силкаи дурустро ҳамеша дар Render бинед.

Бо логин ва пароли қадами 2 ворид шавед. Шумо **админ** ҳастед.

## ⚠️ Маҳдудиятҳои нақшаи ройгон

| Маҳдудият | Оқибат |
|---|---|
| Диски доимӣ нест | **Файлҳои PDF ва муқоваҳо пас аз ҳар навсозӣ ё бозоғозӣ нест мешаванд.** Маълумоти китоб боқӣ мемонад, вале файл не |
| Базаи ройгон тақрибан 30 рӯз | Пас аз ин мӯҳлат база (корбарон, китобҳо) нест мешавад |
| «Хоб»-и сайт | Пас аз 15 дақиқаи бе меҳмон сайт хоб меравад; кушодани аввал то ~1 дақиқа вақт мегирад |

Нақшаи ройгон **барои санҷиш ва нишон додан** аст. Барои истифодаи воқеии факултет ба нақшаи пулакӣ гузаред.

## Гузаштан ба нақшаи пулакӣ (вақте ки тайёр шудед)

Дар `render.yaml`:

```yaml
databases:
  - name: mathlib-db
    plan: basic-256mb        # ба ҷои free
services:
  - type: web
    plan: starter            # ба ҷои free
    disk:                    # диски доимӣ барои PDF-ҳо
      name: media
      mountPath: /var/data
      sizeGB: 1
    envVars:
      - key: MEDIA_ROOT
        value: /var/data/media
```

Нархҳоро дар <https://render.com/pricing> санҷед.

> Базаи ройгонро пеш аз ба охир расидани мӯҳлат ба пулакӣ гузаронед. Баъд аз нест шуданаш маълумот барнамегардад.

## Мушкилот

| Аломат | Ҳал |
|---|---|
| Build failed | Logs-ро кушоед; хатогии охиринро ба ман фиристед |
| Сайт кушода намешавад: «Application failed to respond» | 1 дақиқа интизор шавед (сайт аз хоб мехезад) |
| Бо админ ворид шуда наметавонам | **Environment** → `ADMIN_PASSWORD`-ро иваз кунед → **Save, rebuild and deploy** |
| Файлҳои китоб гум шуданд | Маҳдудияти нақшаи ройгон (болоро бинед) |

Барои иваз кардани пароли админ: Render → `mathlib-bsu` → **Environment** → `ADMIN_PASSWORD` → Save. Пас аз бозоғозӣ пароли нав кор мекунад.
