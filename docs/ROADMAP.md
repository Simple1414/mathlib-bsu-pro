# Roadmap — MathLib BSU Pro

## Version 1.0 — Core

- Login/Register
- User roles
- Book CRUD
- Search/filter
- Download log
- Favorite books
- Book requests
- Dashboards

## Version 1.1 — Reporting

- Ҳисоботи Word/PDF
- Омор аз рӯйи курс, гурӯҳ, ихтисос
- Рӯйхати китобҳои серистифода
- Export барои китобдор

## Version 1.2 — Academic Features

- Рӯйхати адабиёти фаннӣ барои омӯзгорон
- Пайваст кардани китоб ба фанҳо
- Тавсияи китоб ба гурӯҳҳо
- Низоми рейтинги китобҳо

## Version 2.0 — Advanced

- REST API
- Telegram bot барои ҷустуҷӯи китоб
- OCR/metadata extraction
- AI recommendation
- Full-text search бо PostgreSQL
- SSO ё email verification
