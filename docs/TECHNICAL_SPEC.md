# Technical Specification — MathLib BSU Pro

## 1. Мақсад

Сохтани китобхонаи электронии факултети математика барои нигоҳдорӣ, ҷустуҷӯ, пешниҳод, тасдиқ ва истифодаи китобҳо ва маводи таълимӣ.

## 2. Нақшҳо

### Админ
- идоракунии корбарон;
- таъйини нақшҳо;
- идоракунии маълумоти донишгоҳ/факултет/ихтисос;
- назорати омор ва audit log.

### Китобдор
- илова, таҳрир ва тасдиқи китобҳо;
- идоракунии дархостҳо;
- назорати маводи пешниҳодшуда.

### Омӯзгор
- пешниҳод кардани китоб;
- дидани китобҳо;
- истифодаи мавод барои фанҳо.

### Донишҷӯ
- бақайдгирӣ;
- ҷустуҷӯ ва зеркашии китоб;
- дӯстдоштаҳо;
- дархости китоб.

## 3. Моделҳои асосӣ

- University
- Faculty
- Specialty
- User
- Category
- Author
- Book
- FavoriteBook
- BookRequest
- DownloadLog
- AuditLog

## 4. Қоидаҳои бизнес

1. Ҳамаи корбарони нав ҳамчун донишҷӯ сабт мешаванд.
2. Нақши омӯзгор, китобдор ва админро танҳо админ медиҳад.
3. Китоби омӯзгор аввал тасдиқнашуда мешавад.
4. Китоби китобдор ва админ метавонад худкор тасдиқ шавад.
5. Зеркашӣ танҳо барои корбари воридшуда иҷозат аст.
6. Китоби тасдиқнашуда барои донишҷӯ намоён нест.

## 5. Database

PostgreSQL ҳамчун database-и асосӣ истифода мешавад. Барои production backup-и мунтазам ҳатмист.

## 6. Амният

- Django password hashing;
- CSRF protection;
- role-based access;
- file extension validation;
- file size validation;
- `DEBUG=False` дар production;
- HTTPS;
- audit log.
